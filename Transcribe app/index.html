TranscribeIt

Single‑page app to transcribe videos. Paste a link (if CORS/downloadable) or upload a video/audio file. View and download as PDF — all on this page.

Large files are okay, but local engine will be slower for long videos. Start with a short clip to test.
Direct media URLs work best. Many YouTube/Instagram/Twitter/Reddit/Facebook links require a server helper due to CORS/ToS.
Your key is kept in your browser's localStorage. For production, use a server‑side proxy to protect secrets.

Idle

Shortcuts: Ctrl/⌘+Enter transcribe · Esc cancel · Alt+K play/pause · Alt+←/→ seek 5s. Double‑click a [mm:ss] line in the transcript to jump the player there.
Tip: For social links that don't download, use a server helper (e.g., a tiny Cloudflare Worker that resolves media + sets CORS) or supply a direct media URL.

Made with ❤️ — runs entirely in your browser for local mode. APIs are optional. No data leaves your device unless you choose an API provider.
